# 이용약관

버전 2026-09-06

## 1. 이 서비스가 하는 일

LAF 에이전트(이하 "서비스")는 소규모 사업장을 운영하는 분과 그 직원이 **봇**을 만들어 일을 맡기는 도구입니다. 봇은 이름 하나로 만들어지며 아무것도 정해져 있지 않은 상태에서 시작하고, 대화로 직무와 말투를 익혀 갑니다. 한 사람이 봇을 다섯 개까지 만들 수 있습니다.

봇은 다음을 할 수 있습니다.

- 사용자와 대화하고, 정해진 시각에 반복하는 **루틴**을 실행합니다.
- 서비스가 제공하는 **하나의 브라우저**에서 사용자가 로그인해 둔 사이트를 읽고 조작합니다.
- 사용자가 자기 계정으로 연결한 외부 서비스(구글, 카페24, 노션 등)를 사용자의 권한으로 호출합니다.

봇은 인공지능 모델이 내용을 결정합니다. **틀릴 수 있고, 같은 지시에 다르게 답할 수 있습니다.** 봇이 만든 결과는 사용자가 확인한 뒤에 써야 합니다.

## 2. 계정과 컴퓨터

- 로그인은 구글, 카카오, 네이버 계정으로 합니다. 서비스는 비밀번호를 따로 만들지 않습니다.
- 가입한 사람 한 명에게 **가상 컴퓨터(VM) 한 대**가 제공됩니다. 그 사람이 만든 봇은 몇 개든 그 컴퓨터 하나를 함께 씁니다. 다른 사람의 봇이 사용자의 컴퓨터에 들어오지 않습니다.
- 같은 컴퓨터에 관리자 권한을 가진 사람이 있을 수 있습니다. 관리자는 그 컴퓨터의 봇, 한 일의 기록, 봇의 실시간 화면을 볼 수 있습니다. 누가 봇의 화면을 열었는지는 — 본인이든 관리자든 — 기록에 남습니다.

## 3. 봇의 브라우저는 하나입니다

사용자의 봇들은 **하나의 실제 브라우저**에서 일합니다. 한 봇이 어떤 사이트에 로그인하면 다른 봇도 그 사이트에 로그인된 상태가 됩니다. 봇에게는 팀 전체에게 줄 수 있는 만큼의 접근만 주십시오.

봇의 브라우저에 사용자가 직접 입력한 값(비밀번호, 인증번호 등)은 서비스에 기록되지 않습니다. 어디에 무엇을 입력했다는 사실만 남습니다.

## 4. 사람이 먼저 결정하는 행동

서비스에는 **경계**가 있습니다. 경계는 배포마다 정해진 규칙에 따라 특정 행동을 멈추고 사람에게 묻습니다. 사용자가 "다시 묻지 마세요"라고 한 범위는 기록되고, 언제든 철회할 수 있습니다. 어떤 규칙도 봇이 스스로 고칠 수 없습니다.

기본 규칙은 다음을 막거나 사람에게 묻습니다.

- 은행 이체와 결제 실행. 봇은 금융 사이트에서 조회만 합니다.
- 리뷰, SNS, 메시지의 자동 게시. 봇은 초안까지 만들고 게시는 사람이 합니다.
- 손님에게 보내는 알림톡. 매번 사람이 확인합니다.

봇이 사용자의 승인을 받아 한 행동의 결과는 사용자의 것입니다. 봇이 로그인하는 각 사이트의 약관은 사용자가 지켜야 합니다.

## 5. 외부 서비스

봇이 일하려면 서비스 바깥의 회사가 필요합니다. 각 회사에는 그 회사의 약관과 처리방침이 따로 적용됩니다.

| 회사 | 하는 일 | 무엇이 넘어가는가 |
|---|---|---|
| OpenRouter (미국) | 봇의 답을 만드는 인공지능 모델 | 대화 내용, 봇이 브라우저에서 읽은 화면의 텍스트 |
| 솔라피 | 카카오 알림톡 발송 | 받는 사람의 휴대폰 번호와 메시지 변수 |
| 구글, 카카오, 네이버 | 로그인 | 계정 식별자 |
| 구글, 카페24, 노션 | 사용자가 연결을 선택한 경우, 그 계정의 권한으로 호출 | 사용자가 동의 화면에서 허락한 범위의 데이터 |
| 공공데이터포털 (data.go.kr) | 공공 공고 조회 | 검색 조건. 개인정보는 보내지 않습니다 |

자세한 내용은 [개인정보 처리방침](/legal/privacy)에 있습니다.

## 6. 하지 말아야 하는 것

- 법령이나 다른 사람의 권리를 어기는 일에 봇을 쓰는 것
- 본인 소유가 아니거나 사용 권한이 없는 계정에 봇을 로그인시키는 것
- 다른 사이트의 약관이 금지하는 자동화를 봇에게 시키는 것
- 경계를 우회하려고 서비스를 조작하는 것

이런 사용이 확인되면 서비스를 중단할 수 있습니다.

## 7. 서비스의 제공과 중단

- 서비스는 업그레이드나 점검으로 잠시 멈출 수 있습니다. 업그레이드 전에는 데이터베이스 사본을 뜨고, 문제가 있으면 되돌립니다.
- 컴퓨터는 매일 새벽 4시에 백업됩니다. 장애로 복원하는 경우 마지막 백업 이후의 내용은 잃을 수 있습니다.
- 사용자가 창을 닫아도 루틴과 방은 서버에서 계속 실행됩니다. 일대일 대화는 창이 열려 있는 동안만 실행됩니다.

## 8. 요금

요금과 결제 조건은 별도로 안내합니다.

## 9. 데이터

서비스가 사용자에 대해 무엇을 갖고 있고 언제 지우는지는 [개인정보 처리방침](/legal/privacy)에 적혀 있습니다. 사용자는 `설정 → 내 데이터`에서 전부를 파일 하나로 내려받을 수 있고, 같은 화면에서 계정을 지울 수 있습니다.

## 10. 계정을 끝내는 것

`설정 → 내 데이터 → 전부 삭제`에서 자기 이메일 주소를 입력하면 계정이 지워집니다. 봇의 브라우저 프로필, 연결한 서비스의 토큰, 대화, 루틴, 봇 자체가 순서대로 지워지고, 사람이 아무도 남지 않으면 컴퓨터 자체가 없어집니다.

남는 것은 두 가지입니다. 한 일의 기록은 지워지지 않고 가명으로 바뀌어 **1년** 뒤 자동으로 지워집니다. 최근 **30일** 안에 만들어진 백업에는 사본이 남아 있다가 보존 기간이 끝나면 지워집니다.

## 11. 책임의 범위

봇의 답과 행동은 인공지능 모델이 결정합니다. 서비스는 봇이 한 일을 기록하고 사람에게 묻는 장치를 두지만, 봇이 틀리지 않는다고 보장하지 않습니다. 이 항의 문구는 법률 자문 후 확정합니다.

## 12. 약관의 변경

약관이 바뀌면 이 페이지의 버전이 바뀝니다. 사용자가 동의한 시각과 버전은 계정에 기록되고, 내려받는 파일에 포함됩니다.
